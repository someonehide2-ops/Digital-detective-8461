# Mission 1 — Know your computer

## 1. Task / objective
Explain IPOS, identify hardware and software, and describe everyday computer-based systems.

## 2. Work completed
### Task 1.1 — IPOS example: typing and saving a document
| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I press keys and enter text into the document. | Keyboard |
| Processing | The computer interprets the keystrokes and updates the document in memory. | CPU and RAM |
| Output | The updated document appears on the display. | Screen |
| Storage | I save the document so it can be opened later. | SSD or other storage |

### Task 1.2 — Hardware and software
| Item | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enters text and commands |
| Trackpad / mouse | Hardware | Not applicable | Controls the pointer |
| Display | Hardware | Not applicable | Shows visual output |
| SSD | Hardware | Not applicable | Stores files and applications |
| macOS | Software | Operating system | Manages hardware and provides services to applications |
| Safari | Software | Application | Browses websites |
| TextEdit | Software | Application | Creates and edits text documents |
| Activity Monitor | Software | Utility | Displays process and resource information |

### Task 1.3 — Computer systems around me
| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Provides banking services | Card and PIN | Cash or transaction receipt |
| Traffic signal controller | Controls traffic lights | Sensors or programmed timing | Red, amber or green signal |
| Ticket vending machine | Issues travel or event tickets | Selected ticket and payment | Printed or digital ticket |
